Meetings, chronicles and brain-dump now use the AI backend that suits them, instead of whichever
one you picked for dictation — and every summary tells you which model wrote it.

## One setting was doing two incompatible jobs

Polishing a sentence of dictation and summarising an hour-long call want opposite things.
Dictation is a keystroke away from pasting, so speed is everything. A meeting summary is
something you deliberately wait for, and what matters is how much text fits into a single pass.

Until now a single **AI Polish → Backend** choice governed both, and neither answer was right:

- **With Ollama selected**, your first dictation after a few minutes' pause usually got no polish
  at all. Ollama unloads a model when idle, reloading takes longer than the time dictation is
  willing to wait, and when polish doesn't arrive OmWhisper pastes your original words. Working
  as designed, and completely invisible.
- **With Apple Intelligence selected**, an hour-long call was squeezed through roughly forty
  compression passes instead of six. Each pass loses detail.

Now the long jobs pick the backend that fits them and dictation keeps yours. If you have Ollama
set up, meetings, chronicles and brain-dump use it for its much larger capacity; dictation
carries on with whatever you chose. **Nothing to configure — the setting you already have keeps
meaning what it meant.**

Brain-dump benefits most: it was being treated as dictation, so a long ramble through a
cold model would give up and paste your raw words. It now gets the same patience as a meeting
summary, and falls back rather than giving up if Ollama isn't running.

## Every summary says who wrote it

Meeting summaries and chronicles now carry a line like **"Written by Ollama (qwen3.5:latest)"**
or **"Written by Apple Intelligence"**.

This matters more than it sounds. A summary is only as good as the model behind it, and a small
model produces vague, thin notes that look like the feature is broken when it's really the model
being out of its depth. Now you can see which one wrote it and change it if you want something
better. The model name is there deliberately — "Ollama" alone doesn't tell you whether you're
running something small or something capable.

Summaries you edit yourself drop the line, because they're your words at that point. Summaries
written before this release simply don't show one.

## Meetings

- **Meeting titles from Microsoft Teams are clean.** Teams names its windows
  `Your Meeting | Microsoft Teams`, and the whole string was becoming the meeting name.
- **Copy Debug Info reports what meeting detection sees** — which app is using your microphone,
  whether it was recognised as a call, and what the watcher is doing. If a call isn't detected,
  one click during the call captures the reason. App identifiers and states only; never window
  titles, page addresses or anything you said.

## Also

- Recordings and chronicles still never reach a cloud provider, whatever your AI backend is set
  to. That remains enforced in the code rather than by a setting.
