Memory became genuinely searchable in this release — and an on-device AI bug that had been
hiding in plain sight got fixed.

## If AI polish never seemed to do anything, this is why

Apple Intelligence only supports 23 languages and regions. **English (India) is not one of
them** — nor are many others — and macOS still reports Apple Intelligence as "available" on
those Macs. OmWhisper believed it, sent text to a model that refused every request, and then
did what it always does when polish fails: pasted your original text.

So Smart Dictation, Polish Selected Text, Brain-dump and Reply Assist appeared to work and
quietly changed nothing. There was no error, because failing safe is exactly what they were
designed to do.

Now the app checks properly. If the on-device model can't run on your Mac, Settings › AI Polish
says so, names the reason, and tells you your text will paste unchanged until you pick Ollama
or a cloud provider. Meetings and chronicles say the same rather than showing a raw system
error. **Nothing about your setup changed — this only stops the app pretending.**

## Memory

- **Search by meaning.** Search "pricing" and find the page that said "cost structure".
  Results show the passage that actually matched, not a generic preview. Keyword search still
  runs alongside it, so exact terms, error codes and names still behave as before. The first
  time you use it the app indexes what you've already captured in the background; search keeps
  working while that happens.
- **Sees your whole desk.** Memory used to capture only the window you were typing in. It now
  also captures the frontmost window on each of your other displays — the spec you're reading
  on the second monitor is part of your day, and searchable.
- **Captures the page, not the furniture.** Browser and Electron windows were being recorded
  largely as sidebar and tab-strip text. Memory now reads the page content itself, so searches
  find what you were reading rather than the chrome around it.
- **Exclusions.** One sheet, three lists: apps (pick from anything installed, not just what's
  running), sites, and window-title keywords. Nothing is captured from them again.
- **`.env` files are never captured.** No setting, no opt-in — a file whose entire purpose is
  holding secrets shouldn't depend on you remembering to exclude it. Password managers and
  private browsing were already excluded and still are.
- **Chronicles work with Ollama.** Your daily chronicle was written by Apple Intelligence or
  not at all, which meant never, on the Macs described above. If Ollama is your AI backend it
  now writes them, in much larger pieces — which reads better on a busy day.
- Memory's controls are visible in the toolbar instead of hidden behind a "⋯" button.

Memory stays on your Mac. It is off until you turn it on, and it is never sent to a cloud
provider — including chronicles, which is enforced in code rather than by a setting.

## Fixes

- Chronicle generation showed a raw system error ("An unsupported language or locale was
  used") instead of an explanation.
- The nightly chronicle was switched off entirely for anyone using Ollama, silently.
- Summaries of long days were losing their later hours before being written.
- Custom vocabulary and word replacements are unchanged, and the honest position on them is
  unchanged too: replacements and fuzzy correction work on every engine, but engine-level
  biasing measurably does nothing on Apple Speech or Parakeet. It does help Whisper.
