# D4b — Motion + Accessibility Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close Phase D with the polish pass: one calm spring-motion family applied to the
hub's nav/content/dashboard, real keyboard-and-VoiceOver navigation, and two verified AA
contrast fixes — all honoring the design skill's motion philosophy (the 40th-dictation test,
Reduced Motion non-negotiable).

**Architecture:** Motion is centralized in one `PorcelainMotion` helper (a single spring +
a reduced-motion-aware `animation()` wrapper) so every hub surface animates the same way
instead of each view inventing its own timing. The a11y fixes are surgical: two token value
changes (light `dim`/`mint`) verified against WCAG, and converting the sidebar's
`.onTapGesture` nav rows into real `Button`s.

**Tech Stack:** SwiftUI (macOS 26), existing `UI/OmColors.swift` (`porcelainAdaptive`),
`UI/PorcelainComponents.swift`, `UI/HubShellView.swift`, `UI/HubHomeView.swift`. No new deps.

## Global Constraints

- **Motion philosophy (design skill §2), verbatim:** one spring family, reused not reinvented;
  the "40th-dictation test" (no entrance fanfare/confetti — a calm ambient breath is fine, a
  number counting up on every open is NOT); Reduced Motion is **non-negotiable** — shapes go
  static, opacity carries the signal, and continuous animations stop.
- **One spring:** `.spring(response: 0.35, dampingFraction: 0.82)` — the "350ms spring with
  slight overshoot" from the skill's standard timings. Do not introduce a second spring.
- **Reduced Motion gate:** every animation added here reads
  `@Environment(\.accessibilityReducedMotion)` (or routes through `PorcelainMotion`) and
  degrades to no-animation / static.
- **Contrast targets (WCAG AA-normal ≥ 4.5:1, verified):** light `dim` `#66796F`→`#607269`
  (4.41→4.86 on the `#F7FAF8` canvas); light `mint` `#0D9488`→`#0B7D73` (3.74→5.01 on white).
  Change ONLY the light values in `porcelainAdaptive(light:dark:)` — dark values already pass
  (7.0+) and must not change.
- **Fixed type is the design** (skill §3: "system font at native sizes") — Dynamic Type here
  means *verify nothing clips*, not a rebuild to semantic font styles.
- Run `xcodebuild -scheme omwhisper-native -project omwhisper-native.xcodeproj build test`
  after every task; it must say `** TEST SUCCEEDED **` with 219 tests before moving on.

### Task 2: `PorcelainMotion` — one spring family + reduced-motion helper

**Files:**
- Modify: `omwhisper-native/UI/PorcelainComponents.swift`

**Interfaces:**
- Produces:
  - `enum PorcelainMotion { static let spring: Animation }` — the one spring.
  - `View.porcelainAnimation(_ reduceMotion: Bool) -> Animation?` isn't needed; instead a
    `View.motion(_:reduceMotion:)` helper isn't needed either. Keep it minimal: expose
    `PorcelainMotion.spring` and a static `PorcelainMotion.resolved(reduceMotion:) -> Animation?`
    returning `nil` when Reduced Motion is on. Views call
    `.animation(PorcelainMotion.resolved(reduceMotion: reduceMotion), value: …)`.

- [ ] **Step 1: Add the motion helper**

Add near the top of `PorcelainComponents.swift` (after the imports, before `omCard`):

```swift
// MARK: - Motion

/// The hub's single spring family (design skill §2: one spring, reused). ~350ms
/// with slight overshoot. `resolved(reduceMotion:)` returns nil under Reduced
/// Motion so callers degrade to no animation (non-negotiable, skill §2.5).
enum PorcelainMotion {
    static let spring: Animation = .spring(response: 0.35, dampingFraction: 0.82)

    static func resolved(reduceMotion: Bool) -> Animation? {
        reduceMotion ? nil : spring
    }
}
```

### Task 5: Home week-bar calm "breathing" (Reduced-Motion static)

**Files:**

**Interfaces:**

- [ ] **Step 1: Add breathing state + reduced-motion env**

Add to `HubHomeView`'s properties (below `@State private var errorMessage`):

```swift
    @State private var breathing = false
```

- [ ] **Step 2: Apply a slow opacity breath to the bars**

Replace `weekBar(_:)` with (only the `RoundedRectangle` fill/opacity + a repeating animation
added; heights unchanged):

```swift
    private func weekBar(_ stats: HomeStats) -> some View {
        let maxCount = max(stats.last7DaysWordCounts.max() ?? 0, 1)
        return HStack(alignment: .bottom, spacing: 5) {
            ForEach(Array(stats.last7DaysWordCounts.enumerated()), id: \.offset) { _, count in
                RoundedRectangle(cornerRadius: 3)
                    .fill(Color.Porcelain.emerald.opacity(count == 0 ? 0.12 : 0.55))
                    // Calm ambient breath (skill §2: the field breathes, slowly).
                    // Not tied to any action, so it passes the 40th-dictation test;
                    // static under Reduced Motion.
                    .opacity(breathing && count != 0 && !reduceMotion ? 0.78 : 1.0)
                    .frame(height: max(4, 34 * Double(count) / Double(maxCount)))
            }
        }
        .frame(height: 34, alignment: .bottom)
        .padding(18)
        .frame(maxWidth: .infinity, alignment: .leading)
        .omCard()
        .onAppear {
            guard !reduceMotion else { return }
            withAnimation(.easeInOut(duration: 2.5).repeatForever(autoreverses: true)) {
                breathing = true
            }
        }
    }
```

(A 2.5s ease-in-out autoreversing = a ~5s full breath, matching `hub-concept.html`'s
`breathebar`. `.easeInOut(...).repeatForever` is the one exception to "one spring" — a spring
can't loop a breath; documented here as intentional.)
